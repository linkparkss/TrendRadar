# 自动 wmlfadj.exe 样本训练版

该程序以 `潮流收敛.py` 为计算基础：修改当前 Temp 输入文件，调用原脚本的
`run_load_flow()` 启动 `wmlfadj.exe`，然后检查新生成的 `LF.CAL`、`LFCAL.LIS`
和最终失配量。它不会仅凭进程返回码宣布收敛。

## 三个样本规则

| sample_id | Temp 文件 | 自动恢复动作 |
| --- | --- | --- |
| `FC08_GEN_PG_080` | `LF.L5` | 赣丰城三期08-8：`Pg 8.0 -> 10.0` |
| `FC08_LCC_YALUO_500` | `LF.ML4` | 雅砻江正、负极：`2500 -> 3250` |
| `FC08_GEN_OUTAGE_LARGE` | `LF.L5` | 赣丰城三期08-8：`Valid 0 -> 1` |

这些是从三个已标注故障样本反向得到的恢复规则，不是面向任意新故障的通用模型。

## 使用方法

先在 PSASP 中选择目标样本作业并刷新，使 `YOUR_PSASP_TEMP\LF.L0`
显示正确的 Case_No 和 Case_Name，然后关闭 PSASP。程序会在任何写入之前核对
`LF.L0`；不匹配就拒绝运行，防止算错作业。

预览不会修改文件或启动计算：

```powershell
python 潮流收敛_自动训练版.py --config convergence.toml.example --sample FC08_GEN_PG_080
```

确认预览中的 `case_matches` 为 `true` 后执行：

```powershell
python 潮流收敛_自动训练版.py --config convergence.toml.example --sample FC08_GEN_PG_080 --run
```

执行过程为：备份相关输入文件和 `run.json`，条件写入样本恢复动作，删除旧结果，
启动 `wmlfadj.exe`，验证结果。只有明确收敛才保留调整；超时、报错、结果不新鲜、
最终失配超容差或明确不收敛时，都会按原始字节自动恢复输入文件。

如进程被强制终止，可使用结果中的 `run_dir` 手动恢复：

```powershell
python 潮流收敛_自动训练版.py --config convergence.toml.example --restore-run "<run_dir>" --run
```
